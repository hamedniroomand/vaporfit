# MCP server

`vaporfit mcp` serves three read-only tools over stdio:

- `list_components`
- `get_component`
- `get_summary`

`list_components` and `get_component` give the interop verdict in `verdict` and the pure verdict in `pure`. The `verdict` filter of `list_components` uses the interop verdict.

```sh
npx vaporfit mcp
npx vaporfit mcp --root path/to/project
```

The tools do not change files. This command needs `devframe` and `@devframes/agentic` installed next to vaporfit. The check command does not download them.
