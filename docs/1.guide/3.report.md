# Static report

`vaporfit report` writes the same page as `vaporfit ui`, with the report baked into the files.

```sh
npx vaporfit report --out dist/vaporfit
npx vaporfit report --root path/to/project --out dist/vaporfit
```

Open the folder with any static file server. The detail view works without a running analyzer.

The command exits 0 when the report has findings. A bad flag still exits 2. The check command keeps its own exit codes.
