# Vite DevTools panel

The panel is a separate export. A normal import of `vaporfit` does not load it.

```ts
import { vaporfit } from 'vaporfit/devtools';

export default {
  plugins: [vaporfit()],
  devtools: true,
};
```

Install `@vitejs/devtools-kit` in the app. It is an optional peer dependency (`^0.8.0`). The panel needs Vite 8.3 or later and `devtools: true`.

The panel shows the same report as `vaporfit ui`.
