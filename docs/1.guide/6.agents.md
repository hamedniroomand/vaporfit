# AI agents

An agent can read the report of a project.
An agent can also read this site without the HTML.

## The report of a project

`npx vaporfit --json` prints the report as JSON.
The report field `schemaVersion` has the value `0`.
Schema version 0 is unstable.

`npx vaporfit mcp` serves three read-only tools over stdio.
The [MCP server](/guide/mcp) page lists the tools.

## This site

| Address          | Content                                                      |
| ---------------- | ------------------------------------------------------------ |
| `/llms.txt`      | A list of the pages. Each item links to the Markdown source. |
| `/llms-full.txt` | All pages in one text file.                                  |
| `/<path>.md`     | The Markdown source of one page, for example `/rules.md`.    |
| `/sitemap.xml`   | The address of each page.                                    |

The library table and the rule table are Markdown tables in the page source.
The script `scripts/docs-data.ts` writes them before each build.

Each page has a "Copy page" button. It copies the Markdown source of the page.
