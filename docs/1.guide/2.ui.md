# Local UI

`vaporfit ui` analyzes the project and opens a browser on your machine.

```sh
npx vaporfit ui
npx vaporfit ui --root path/to/project
```

The page shows the same report as `npx vaporfit --json`:

- **Summary:** the interop and pure counts with a bar, the plugin state, the rules that hold back the most components, the blocked components, and the Vue libraries
- **Components:** each component with its interop and pure verdicts. Blocked components come first. You can search the paths and filter by tier, verdict, and rule
- **One component:** the findings, grouped by rule, with each place, the chain from your component to the cause, and links to the probes, issues, and sources
- **Rankings:** each rule with the number of components that it holds back. A click opens the components of that rule
- **Libraries:** the Vue libraries with data and with no data

The filters are in the address, so you can share a link to a filtered list.

`"ready" means that vaporfit found no known problem. It does not test behavior.`

The page watches project files and refreshes the report. It does not edit source files. It does not ask you to log in.
