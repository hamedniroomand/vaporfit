# Local UI

`vaporfit ui` analyzes the project and opens a browser on your machine.

```sh
npx vaporfit ui
npx vaporfit ui --root path/to/project
```

The page shows the same report as `npx vaporfit --json`:

- the interop counts and the pure counts
- the component list, with a filter for `ready`, `blocked`, and `unknown`
- one component, with each finding, its chain, and a link when the evidence has a URL
- the rankings
- the library names in `withData` and `withoutData`

`"ready" means that vaporfit found no known problem. It does not test behavior.`

The page watches project files and refreshes the report. It does not edit source files. It does not ask you to log in.
