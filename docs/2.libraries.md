# Libraries

This page lists each library in the data files.
Each row uses the fields in the library file.
This page does not add a status.

A maintainer corrects a row in the library file.
The maintainer changes the library file.
The maintainer puts evidence in the same change.
One evidence is a probe in `repros/`.
One evidence is a maintainer text with a link.
One evidence is an issue link.

Each row has a link with the text "edit this row".
The link opens the library file.

The cell text "No declaration" means that the file has no maintainer statement.
The mark "stale" means that the verified date is more than 30 days before the build date.

The rules are on the [rules](/rules) page.

The script `scripts/docs-data.ts` writes the table from the files in `data/libraries`.
